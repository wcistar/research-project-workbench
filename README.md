# 个人研究与求职工作台

一个面向经济学研究生的本地个人工作管理工具，用于集中记录硕士论文、实习报告、秋招投递和成果文件。项目使用 Streamlit 提供网页界面，使用 SQLite 在本机保存数据。

仓库公开版本默认进入**演示模式**。仓库中只允许包含完全虚构的演示数据，不包含真实公司、真实岗位、真实论文题目、个人文件路径或个人信息。

## 项目背景

研究生阶段的论文写作、实习项目、行业报告和求职投递通常分散在多个文档、表格和收藏夹中，截止日期、下一步行动与已完成成果不容易统一查看。本项目将这些信息整理到一个适合个人使用的本地工作台中。

本项目是轻量级个人工具，不是多人项目管理系统，也不替代专业招聘管理平台。

## 当前页面

### 1. 总览

- 今日待办、未来 7 天截止、论文总体进度和秋招已投递指标。
- 本周重点与论文、实习报告、秋招目标进度。
- 即将截止事项、最近更新记录和最近完成成果。
- 数据较少时不显示无意义的大型图表。

### 2. 论文进度

- 维护论文题目、当前阶段、总体完成比例和下一阶段节点。
- 管理章节或研究模块的阶段、进度、问题、文件和截止日期。
- 记录每日论文工作。
- 管理原有论文类相关事项。

### 3. 实习与报告

- 以项目和报告为主要管理对象。
- 展示正在进行的报告卡片。
- 记录模块、进度、资料来源、文件路径和带教反馈。
- 记录每日完成、明日计划和遇到的问题。
- 管理原有实习及报告类相关事项。

### 4. 秋招投递

- 展示待投递、已投递、笔试、面试和 Offer 数量。
- 展示简洁的招聘进度漏斗。
- 按状态、城市、岗位类型和公司关键词筛选。
- 管理投递记录、JD 链接、简历版本和下一步行动。
- 管理原有秋招类相关事项。

### 5. 成果归档

- 展示成果总数、本月完成、论文章节和报告成果指标。
- 识别已完成但尚未归档的论文模块和实习报告，由用户确认后一键归档。
- 归档论文章节、政策整理、行业报告、周报、简历和面试复盘。
- 按成果类型与所属项目筛选。
- 保存成果说明及文件链接或本地路径。

## 技术栈

- Python
- Streamlit
- SQLite
- Pandas
- Plotly

项目不使用外部 API，不包含登录功能，也不包含爬虫。

## Windows 安装和运行

建议使用 Python 3.10 或更高版本。安装 Python 时勾选 **Add Python to PATH**。

打开 PowerShell，进入解压后的项目目录：

```powershell
cd "你的项目目录"
```

首次使用时安装依赖：

```powershell
python -m pip install -r requirements.txt
```

启动工作台：

```powershell
python -m streamlit run app.py
```

浏览器通常会自动打开。若未打开，可访问终端显示的本地地址，通常是 `http://localhost:8501`。在终端按 `Ctrl+C` 可停止工作台。

如果已经创建桌面快捷方式，也可以直接双击“个人研究与求职工作台”。

## 演示模式与个人模式

应用启动时默认选择**演示模式**。在左侧边栏的“数据模式”中可以切换：

- **演示模式**：使用 `data/demo.db`，只包含完全虚构的数据，适合截图、演示和公开部署。
- **个人模式**：使用 `data/local_data.db`，保存个人真实进度、投递和文件路径，仅供本机使用。

切换模式后，所有页面会立即读取所选数据库。两个数据库完全独立，在演示模式中进行的新增、编辑和删除不会影响个人模式。

### 面试展示与公开部署

本机正常启动时不设置任何开关，因此左侧仍可切换“演示模式”和“个人模式”。公开部署时应设置：

```toml
WORKBENCH_DEMO_ONLY = true
```

开启后，应用会隐藏数据模式选择框、强制连接 `data/demo.db`，并显示“当前为公开演示版本”。如果使用 Streamlit Community Cloud，可在部署页面的 **Advanced settings → Secrets** 中加入上面的配置。

公开仓库或部署包还必须只包含 `data/demo.db`，不能包含 `local_data.db`。这是第二层保护：即使界面逻辑以后被误改，公开环境也没有个人数据库可读取。

公开截图或部署后应确认侧边栏显示：

```text
当前为公开演示版本
公开环境已关闭个人模式，仅使用虚构示例数据。
当前数据库：demo.db
```

如需在本机临时预览“面试官看到的版本”，可在 PowerShell 中运行：

```powershell
$env:WORKBENCH_DEMO_ONLY="true"
python -m streamlit run app.py
```

关闭该 PowerShell 窗口后，临时开关自动失效；下一次按原方式本地启动即可继续切换个人模式。

## 数据库与安全迁移

数据库位置：

```text
data/demo.db         # 虚构演示数据，可以随仓库公开
data/local_data.db   # 个人真实数据，禁止上传
data/workbench.db    # 迁移前旧版真实数据库，禁止上传
data/backups/        # 所有本地备份，禁止上传
```

现有真实数据库没有被删除。隐私模式启用前的 `workbench.db` 已完整复制为 `local_data.db`，个人模式继续使用该副本。

当前主要数据表：

- `tasks`：原有通用事项。
- `applications`：秋招投递。
- `achievements`：成果归档。
- `app_settings`：论文总体信息和个人目标。
- `thesis_progress`：论文章节或研究模块进度。
- `thesis_logs`：论文工作记录。
- `internship_projects`：实习项目与报告。
- `work_logs`：每日工作记录。
- `activity_log`：最近更新记录。

## 备份与恢复

个人数据备份前先停止工作台，再复制：

```text
data/local_data.db
```

建议将副本放入其他文件夹并在文件名中加入日期。恢复时先停止工作台，再用备份文件替换 `data/local_data.db`。

隐私模式修改前的自动备份保存在：

```text
data/backups/workbench-before-privacy-mode-20260729.db
```

不要在工作台运行并写入数据时覆盖数据库。

## 已知限制

- 仅适合单人在本地使用。
- 不会在工作台关闭时主动发送截止提醒。
- 不上传附件，只保存文件链接或路径文字。
- 本地文件路径变化后不会自动修复。
- 招聘漏斗依据当前状态近似统计，不保存完整状态历史。
- 表格在非常窄的屏幕上可能需要横向滚动，但默认只展示核心字段。

## GitHub 隐私提示

`.gitignore` 默认排除：

- `data/local_data.db` 和旧版 `data/workbench.db`；
- `data/backups/` 中的所有备份；
- 除 `data/demo.db` 之外的其他 SQLite 数据库；
- `work/` 与 `outputs/`；
- 虚拟环境和 Python 缓存；
- `.env`、Streamlit 密钥和本地覆盖配置。

仓库中的 `demo.db` 仅包含“示例科技公司A”“某产业咨询公司”“示例国企集团”等虚构记录。公开上传前仍应人工执行以下检查：

1. 确认 Git 待提交文件中只有 `data/demo.db`，没有 `local_data.db`、`workbench.db` 或 `backups/`。
2. 搜索代码和文档中是否出现本机盘符、用户名、联系方式或真实公司名称。
3. 确认截图来自演示模式。
4. 启动公开版本，确认没有模式选择框，并显示“当前为公开演示版本”和 `demo.db`。
5. 不要上传 `outputs/` 中可能包含旧数据库的历史压缩包。
